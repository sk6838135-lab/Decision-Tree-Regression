1. Introduction

Decision Tree Regression is a supervised machine learning technique used to predict continuous numerical values. It learns decision rules from input data and uses them to estimate an output.

In this project, we predict a student's exam marks based on the number of hours studied per day. Users can enter their own study hours in the interactive calculator to see an example prediction.

2. Description and Working

A decision tree divides a dataset into smaller groups using rules based on input features. The starting point is called the root node, each decision is a split, and the final outcomes are called leaf nodes.

Steps involved

  1. Collect data containing study hours and exam marks.
  2. Select study hours as the input and marks as the target.
  3. Train the Decision Tree Regression model.
  4. Enter a new study-hour value.
  5. Use the model to predict the estimated marks.
  6. Visualize the data and evaluate prediction errors.

6. Important Formula

Mean Squared Error (MSE)

MSE measures the average squared difference between actual and predicted marks.

MSE = (1/n) × Σ(yᵢ − ŷᵢ)²
  • n: Number of observations.
  • yᵢ: Actual marks.
  • ŷᵢ: Predicted marks.

Mean Absolute Error (MAE)

MAE = (1/n) × Σ|yᵢ − ŷᵢ|

Lower MAE and MSE values generally indicate smaller errors on the evaluation data. A decision tree regression model selects splits to reduce variation in the target values within its groups.

7. Simple Python Implementation

This short program trains a Decision Tree Regression model, accepts study hours from the user, predicts marks, and displays a graph.

Install the libraries

pip install pandas matplotlib scikit-learn

Python code

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.tree import DecisionTreeRegressor

# Dataset
data = {
    'Hours': [1, 2, 3, 4, 5, 6],
    'Marks': [40, 50, 60, 70, 80, 90]
}

df = pd.DataFrame(data)

# Input and output
X = df[['Hours']]
y = df['Marks']

# Train the model
model = DecisionTreeRegressor(random_state=0)
model.fit(X, y)

# Predict marks
hours = float(input("Enter study hours: "))
new_data = pd.DataFrame({'Hours': [hours]})
prediction = model.predict(new_data)

print("Predicted Marks:", round(prediction[0], 2))

# Display graph
plt.scatter(X['Hours'], y, label="Actual Marks")
plt.step(
    X['Hours'],
    model.predict(X),
    where='mid',
    color='red',
    label="Decision Tree"
)
plt.xlabel("Study Hours")
plt.ylabel("Marks")
plt.title("Decision Tree Regression")
plt.legend()
plt.show()

Example output

Decision trees predict using learned splits. Their prediction graphs are step-like, rather than straight lines. This tiny dataset is for practice and is not suitable for real exam-score predictions.
